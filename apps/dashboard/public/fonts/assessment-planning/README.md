These fonts are loaded only by assessment planning documents.

- Carlito Regular and Bold: https://github.com/google/fonts/tree/main/ofl/carlito
  (SIL Open Font License, included in OFL.txt).
- Aref Ruqaa Regular: https://github.com/google/fonts/tree/main/ofl/arefruqaa
  (SIL Open Font License, the same license text as OFL.txt), for the handwritten
  remarks on Massar student statements.
- Kalam Regular, Caveat (variable) and Reenie Beanie:
  https://github.com/google/fonts/tree/main/ofl/{kalam,caveat,reeniebeanie}
  (SIL Open Font License, the same license text as OFL.txt), for the
  handwritten French and English remarks on Massar student statements.
- FreeSerif Regular and Bold: GNU FreeFont 20120503,
  https://ftp.gnu.org/gnu/freefont/freefont-ttf-20120503.zip
  (GNU GPL with the font embedding exception; license included in FreeFont-COPYING.txt).
  Corresponding sources: https://ftp.gnu.org/gnu/freefont/freefont-src-20120503.tar.gz

The original font files are unmodified. Carlito and FreeSerif match the font
families used in the reference assessment schedule. No external font service
is contacted when viewing or printing a document.
