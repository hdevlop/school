# Empty-school first-use fixes — 2026-10-22

The owner's real-UI report covered academic catalogs, people, placements,
attendance, payments and routines. This follow-up changes source behavior and
tests the critical enrollment paths on the isolated local `school_history_test`
fixture. It does not claim a fresh browser walkthrough or deployment.

## Changes

- A student can be enrolled with no fees. Any supplied fee still receives the
  normal nested validation; enrollment staff without financial access still
  cannot submit charges. The Fees step explains that billing is optional and
  links to Financial → Fee Types in another tab, preserving the wizard.
- The first wizard step calls the guarded, advisory
  `POST /students/validate-admission` endpoint. It checks code uniqueness and
  section capacity using the same domain rules as creation. These checks make
  no student/account/fee writes, and creation repeats them transactionally.
- Moving on the current placement's start date uses the existing audited
  enrollment correction path. It does not create a zero-length interval.
  Administrator/principal authorization, capacity checks, future-date limits,
  and attendance/grade integrity checks remain enforced. Later transfers retain
  the previous placement. Student profile editing remains profile-only.
- Section list/detail cards show enrolled-student counts. Class/section forms
  show occupancy and mark full sections. Counts follow the selected year's
  latest active placements and refresh after student/enrollment mutations.
  Count queries apply ownership, year and requested IDs together; existing
  repository reads and the recorded ownership baseline are unchanged.
- A section deletion confirmation includes class, section and year.
- The student Alerts dot appears only for active alerts from the same query
  used by that student's tab. A family fee summary labels its combined balance
  as a family account instead of naming the first unpaid child/fee.
- Routine cells show the teacher on both desktop and mobile. Recurring fee
  creation/editing labels the net figure as the total for the billing period.
- Cycle-form submission no longer propagates an already-handled rejected
  dialog promise into the form event. The student wizard shows expected server
  refusals without throwing them as uncaught errors. A browser retest of the
  development overlay is still needed.
- New and changed user-facing messages exist in English, French, Arabic and
  Spanish.

The Student Details **School years** tab was removed at the owner's request.

appear in Overview for administrators and principals, without the year-history
