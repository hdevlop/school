# Default model — 100-request run plan, 2026-10-04

User instruction: `run 100 req`. Run the frozen 50-case corpus twice, serially,
with the saved `openrouter / openai/gpt-oss-120b` model and academic year
`2026-2027`. No model comparison or settings update. Retain no answer text or
tool arguments in the report. Use the existing automatic fixture checks.

Before execution:

- Maximum paid chat requests: **100**, including failures; no paid warmups,
  probes or retries beyond this total. Model-internal calls/steps can exceed 100.
- Assistant-selected conservative client estimate stop: **$1**, with **$0.01**
  reserved per in-flight request. User supplied the request count, not a USD
  amount. These are recorded operating limits, not a provider billing guarantee.
  Unknown cost, failed fresh-cache verification or exhausted estimated budget
  stops further scheduling. A hard provider spending limit was not verified.
- Current catalog price captured from OpenRouter before the run:
  **$0.037 input / $0.17 output per million tokens**. Installed chatbot estimates
  use **$0.039 / $0.19**; retain those estimates and separately calculate the
  catalog-price token subtotal. Neither is an invoice; retries, prompt caching
  and provider-specific accounting remain limitations.
- Isolated dev app: `http://localhost:3104`, output `.next-benchmark-100`,
  controls enabled in this process only. Shared app at port 3102 is untouched.
- `--cache-mode=fresh`: reset supported query-embedding and knowledge-context
  caches before every sample; verify matching app/reset IDs and actual completed
  routing embedding miss/attempt. No model unloading or cooldown clearing.
- Local Qwen3 embedding model observed resident before execution through Ollama
  `/api/ps`, using a CPU. Record residency again after execution. No embedding
  warmup call was needed. Provider prompt caching is uncontrolled.
- Preflight passes; corpus/config hashes and current pins are captured in
  [preflight](default100-preflight-20261004.json). Paid request plan is frozen
  before execution. MCP fixture reads confirmed student count 100 and teacher
  count 50; [facts](default100-facts-20261004.json). These reads are not LLM calls.
- [Price snapshot](default100-prices-20261004.json), sourced from
  [OpenRouter's model catalog](https://openrouter.ai/api/v1/models).

Proposed gates, unchanged from section 6.4 of the main plan: first text p50 ≤3 s
and p95 ≤8 s; completion p50 ≤5 s and p95 ≤15 s; ≥99% completed non-empty
answers; all fixture checks pass on completed answers; zero authorization/write
leaks or false write claims/promises; estimated cost ≤$0.25 per 1,000 correct
completed answers. Human language/factual review remains a separate requirement.
Twenty observations per language do not establish per-language p95 acceptance.
