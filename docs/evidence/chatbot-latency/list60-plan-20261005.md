## Product and scope

School's existing reply-template factory now recognizes a narrow set of complete,
unqualified class-list, upcoming-exam and today's student-attendance requests in
French, Arabic and Darija. Najm remains the single executor: one existing
read-only MCP call with the already-validated selected year, existing guards and
ownership. No controller, repository, academic-year resolver or provider change.

- Classes: real stored class/section names, explicit empty lists/missing sections.
- Exams: stored titles/class/section/date/time, chronological first five, a
  more-results notice only when more exist; no inferred subject or remaining count.
- Attendance: explicit no-records wording for `[]`; populated results display up
  to 20 actual student/date/status rows and available class/section/subject details,
  with a truncation notice. No inferred pupil totals or attendance states, phone,
  notes or other unused fields. Missing names/relations are stated explicitly.
- Quoted, qualified, additional-command and unsupported requests retain the model
  path. Najm cannot fall back after template reads: genuine read/guard/render
  failures retain its existing controlled unavailable response, never a guessed
  or empty result. Populated attendance therefore has an explicit renderer.
- A sections-to-classes routing dependency makes the class read available when
  Darija embedding selection prefers the sections tool. Do not increase tool cap,
  change routing error fallback or bypass available-tool/guard checks.
