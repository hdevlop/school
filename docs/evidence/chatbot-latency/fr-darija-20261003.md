## What changed between the runs

- **Teacher count.** There was no count tool, so the model counted the list
  `teachers_get_teachers` returned and answered 42, 62 and 84 instead of 50.
  `GET /teachers/count` (`teachers_get_teacher_count`) counts the rows the
  list returns, ownership included. After: 50 in all four count answers.
- **Reply language.** A Darija question whose only Latin text was a student
  name was answered in English; a Darija class question whose tool result held
  French class names was answered in French. The system prompt now says to
  judge the language by the user's own words, and that Arabic script always
  gets an Arabic-script reply. After: no wrong-language reply.
- **Classes in Arabic.** "الأقسام" usually means class groups (2B) in Moroccan
  schools, so the Arabic and Darija class cases now accept
  `sections_get_sections` as well as `classes_get_classes`. The answer must
  still name CM2 and 1AC.
- **Scorer.** A tool call whose input failed validation no longer satisfies an
  expected tool group. Before, `missing-student-ary` passed although its only
  call (`search_search_students`) was rejected for malformed input.

## Darija routing

After the count and language fixes, both Darija failures were tool routing:

| Case | Offered by routing | Missing |
|---|---|---|
| `students-and-teachers-ary` | teacher tools only; the model called nothing | `students_get_student_count` |
| `missing-student-ary` | assessments, dashboards, `teacher-profile_get_my_students` | `search_search_students` |

The embedding model scored every tool between 0.63 and 0.67 for these Darija
questions, against 0.83 for the right tool on the French equivalent. Adding
Darija words to a tool description did not lift `students_get_student_count`
into the list.

**Semantic phrases were rejected.** When any phrase clears the similarity
threshold (0.45), the router uses phrase matches alone and ignores the
description embeddings. Measured on this model, a Darija phrase scored only
0.50–0.60 for the question it was written for, with wrong tools close
behind, and the unrelated "Liste des véhicules en maintenance" scored 0.456
against a class-list phrase: it would have been routed to the class list only.

**Fix: rewrite Darija to Modern Standard Arabic before routing.** The same
questions in MSA rank the right tools first ("كم من تلميذ وكم من أستاذ" puts
both count tools on top). `najm-rag` 2.1.3 adds `rewriteRoutingQuery`, and
School passes `rewriteDarijaForRouting`
(`packages/server/src/modules/chat/darijaRouting.ts`), a word list of about
110 common Darija words (شحال → كم, وريني → اعرض, ديال dropped, فال → في ال).
Only the text routing embeds changes; the model reads the user's own words.
English, French and Spanish questions are untouched, and MSA questions change
only where they use a Moroccan school word (نقط → نقاط, فرض → اختبار); a test
pins both. The two student-grade tools also gained French and Arabic
descriptions.
